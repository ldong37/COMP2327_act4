- Event Handling
- Signals
- Slots
- PySide6

## Author

Dong Le Quoc Bao

## Additional Information

This project is a Contact Manager desktop application built with PySide6.

- The user enters a contact name and a 10-digit phone number. The Add Contact
  button is enabled only when both inputs are valid.
- Adding a contact places it in the table, clears the inputs and returns focus
  to the name field.
- Selecting a row in the table enables the Remove Contact button. Removing a
  contact asks for confirmation first.
